# «Спогади» — пакет MVP A для Claude Code

Це **вхідні матеріали та технічне завдання**, не побудований сайт. Візуальні референси й більшість авторських медіафайлів ще не надані, тому першою метою є **працездатна оболонка**. У каталозі вже є п'ять кодових джерел і готові двомовні дані для дев'яти майбутніх знахідок.

## Як використати на MacBook Air, без GitHub

1. Розпакуй ZIP у папку, яку зручно відкрити в Claude Code.
2. Відкрий **Claude Code в цій папці**. Якщо користуєшся CLI, виконай `cd "<шлях до папки>"`, потім `claude` (лише якщо CLI вже встановлений).
3. Скопіюй в чат Claude Code **тільки текст із `START_PROMPT.txt`**. Усі інші файли вже локально в його робочій папці — не надсилай 70 КБ вихідних кодів у повідомлення.
4. Claude Code має прочитати `TASK.md` і `CLAUDE.md`, створити `index.html` і робочі файли, а тоді провести **один** smoke test. Якщо використовуватиме браузер, не дозволяй безкінечних циклів виправлень.
5. Для перевірки після створення сайту, відкрий термінал у тій самій папці, виконай `python3 -m http.server 8000`, відкрий `http://localhost:8000`. Зупинити сервер — `Ctrl+C`.

## Файли для перегляду
- `START_PROMPT.txt` — короткий єдиний запит до Claude Code (~1/4 сторінки).
- `TASK.md` — повне ТЗ з межами, станами й acceptance tests.
- `CLAUDE.md` — постійні правила роботи над проєктом.
- `docs/FOREST_MAP.md` — коротка навігація по 1250 рядках лісу, щоб Claude не читав усе без потреби.
- `docs/SOURCES.md` — що перевірено, що бракує, що не змінювати.
- `content/works.json` — 10 робіт, 9 знахідок, автори, тексти й попередні переклади.
- `content/exhibition.json` — українські/англійські дані про виставку й університет.
- `sources/*.html|js` — оригінали або точні реконструкції з надісланих користувачем матеріалів, залишити без редагування.

**Відповідно до затвердженого варіанта A:** роботи ще не вставляються ні в артефакти, ні в модальні вікна; скрипти зберігаються та, за можливості, відкриваються окремо для технічної діагностики. Перший драфт не є готовою публічною виставкою.

## Як заощадити залишок ліміту
Один новий чат Claude Code, один стартовий промпт, без пояснень коду й без десятків уточнень. Не просити одночасно додавати AI-чат, фінальні зображення та вебхостинг. Після першого запуску залишити окремим списком несправності для наступної ітерації. **Використання певного відсотка ліміту не можна гарантувати**, навіть якщо пакет короткий.
